# Owner admin site

Use the existing Astro repository for a second Vercel project. Preserve Sidework's monochrome design and fonts. This is an Operate surface: a compact signup table, text search, status and consent filters, real signup and last-login dates, and clear empty/error states. No new invite codes, email sending, account deletion, or approval controls.

The admin deployment serves only admin routes. Main-site GitHub OAuth verifies the owner, then issues a short-lived, single-use Firestore handoff code bound to a browser PKCE challenge. The admin deployment consumes it with its HttpOnly flow cookie and starts its own origin-bound session. Recheck the configured numeric owner ID and current approval on every admin request. Legacy cookies never grant admin access. No account data is read before authorization.

Use separate admin session secrets and keyless Vercel OIDC access to the same Firestore database. Configure trust for the exact second Vercel project. No browser Firestore access or service-account keys.

Implementation: (1) auth and handoff tests; (2) owner gate and data query; (3) dashboard and login UI; (4) deployment configuration; (5) tests, mobile/desktop and live access checks; (6) independent finish/security review and operational docs. Keep both deployments on main.
